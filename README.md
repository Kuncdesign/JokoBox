# JokoBox: The Reactive Laser Engine
JokoBox is not just another box generator. It is a high-performance web tool designed for laser cutting professionals who demand speed, precision, and a clean workflow.

### Why JokoBox?

🚀 Fastest Workflow (Zero Latency)
No "Generate" button. Every keystroke is a command. Input your numbers, and the pattern draws itself instantly in a live reactive preview.

🛠 Built for Production (The "Nglegowo" Engine)
Cleanest SVG output in the industry. Automatically strips unnecessary browser attributes to ensure 100% compatibility with CorelDraw and RDWorks. No more locked files or broken paths.

📐 In-App Intelligence

Auto-Nesting: Smart positioning to save your material.

Dynamic Labels & LaserPath: Live visual cues showing start points (Magenta Marker) and cutting directions (Arrows).

Smart Units: Seamlessly toggle between mm and inch with real-time value conversion.

🎨 Advanced View Styles
Switch between Wood (Visual Presentation), Grey (Neutral), and LaserPath (Technical Blueprint) with a single click.
